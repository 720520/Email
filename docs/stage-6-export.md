# 阶段 6：每日基金净值与异常 Excel 导出

## 输出约定

每个业务日期生成一个固定名称的工作簿：

```text
data/YYYY/MM/DD/exports/每日基金净值汇总.xlsx
```

文件名由 `storage.daily_export_filename` 配置，但必须是没有目录部分的 `.xlsx` 文件名，防止导出路径越界。

## 工作表结构

### 基金净值

字段顺序固定为：

1. 日期
2. 产品代码
3. 产品名称
4. 单位净值
5. 累计净值
6. 资产净值
7. 来源

顶部展示基金数量、当日异常数量和资产净值合计。数据按产品代码、产品名称排序，产品代码按文本保存，日期和数值保留为 Excel 原生类型。

### 异常记录

异常列包括日期、异常分类、严重级别、产品信息、来源文件、工作表、行号、字段、原始值、说明和处理状态。分类规则包括：

- `日期缺失`
- `产品重复`
- `净值为空`
- `格式错误`
- `字段缺失`
- `文件异常`
- `其他异常`

异常按创建日期而非原邮件日期统计。因此，对历史附件执行人工重新解析时，新产生的异常会进入重解析当天的报表，便于运营人员跟踪当日待办。

## 可靠性设计

- 导出查询只读取指定日期的有效净值，不修改业务历史。
- 工作簿先写入同目录临时文件，写盘成功后使用原子替换发布。
- 若构建或保存失败，旧版本保持不变，临时文件自动清理。
- 每次导出在 `job_run` 中保存开始时间、结束时间、触发方式和成功或失败状态。
- 外部文本在写入前清理 Excel 不支持的控制字符，并阻止公式注入。
- 工作簿启用自动筛选、冻结窗格、打印标题、横向打印和适应页宽。
- 单位净值和累计净值展示八位小数；资产净值使用千分位和四位小数。
- 异常严重级别使用条件格式：错误为红色提示，警告为黄色提示。

## 人工执行

```powershell
.\.venv\Scripts\python.exe -m app.cli.export_daily --date 2026-07-24
```

省略日期时，使用 `storage.archive_timezone` 对应的当天日期。

## 测试与验收

自动测试覆盖：

- 双工作表名称、字段顺序和数据类型
- 公式、数值格式、筛选、冻结窗格、表格对象和条件格式
- 上海时区的异常日期边界
- 空数据日期仍能生成结构完整的报表
- 导出成功和失败任务审计
- 构建失败时旧报表不被覆盖
- Excel 公式注入防护

样例工作簿还经过逐工作表渲染和公式错误扫描，确认长基金名称、来源文件名和异常说明均可见。
