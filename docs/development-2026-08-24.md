# 2026-08-24 开发记录

## 本轮目标

本轮开发围绕运营后台视觉重构、产品与净值工作区整合、租户级备案资料复用三项需求展开。
业务功能和租户隔离边界保持不变，同时加强净值更新检查、开户材料复用、文件版本和审计能力。

## 已完成功能

### 前端视觉与交互重构

- 建立暖色编辑部风格的设计体系，统一画布、侧栏、标题、面板、按钮和状态色。
- 重构运营概览、产品中心、报表中心和报表编辑页面。
- 产品信息默认使用卡片呈现，并保留表格切换。
- 修复长产品名称、份额信息和卡片底部操作区的字段溢出。
- 增加 `Ctrl/Cmd + K` 快捷导航入口。

### 产品中心

- 将原“产品要素”和“基金净值”合并为“产品中心”。
- 产品中心内部提供“产品台账 / 净值明细”切换。
- 旧 `/fund-nav` 地址兼容跳转到净值明细视图。
- 产品卡片按主体归纳 A/B/C 等份额。
- 支持按指定日期展示已更新、部分更新和待更新状态。
- 支持仅查看待更新产品，并保留历史曲线和净值汇总导出。

### 租户备案资料库

- 每个租户独立维护本私募牌照的公司、人员、联系和业务资料。
- 根据开户清单及已填写开户包归纳初始文本字段和文件字段。
- 初始模板仅保存字段结构，不写入身份证号、手机号等真实敏感值。
- 管理员可以新增、修改、排序和删除字段。
- 字段类型分为“可复制文本”和“上传文件”；字段创建后不能直接切换类型。
- 普通用户可查看、复制文本、下载资料清单和文件，但不能修改或上传。
- 字段删除采用软删除，历史文件版本与审计记录继续保留。

### 文件版本与留痕

- 文件上传按租户和字段隔离存储，默认单文件上限为 100 MB。
- 每次上传生成新的不可变版本，不覆盖旧文件。
- 页面展示版本号、文件名、大小、上传人和上传时间。
- 支持下载最新版或任意历史版本。
- 以下操作写入追加式 HMAC 审计链：
  - 字段新增、修改和删除；
  - 文本资料更新；
  - 文件版本上传；
  - 文件版本下载；
  - TXT 资料清单导出。

## 权限模型

| 操作 | 租户管理员 | 运营人员 | 只读用户 |
| --- | --- | --- | --- |
| 查看备案资料 | 是 | 是 | 是 |
| 复制文本/下载清单 | 是 | 是 | 是 |
| 下载文件版本 | 是 | 是 | 是 |
| 编辑文本字段值 | 是 | 否 | 否 |
| 新增/修改/删除字段 | 是 | 否 | 否 |
| 上传文件新版本 | 是 | 否 | 否 |

前端仅隐藏无权操作，最终权限由后端 `UserRole.ADMIN` 强制校验，直接调用接口同样返回 403。

## 部署说明

GitHub Pages 只能托管静态前端，无法承载 FastAPI、数据库、文件存储、PPTX 生成和审计服务。
如需公开测试，应将前端与后端分开部署，或使用同一域名反向代理 `/api`。公开环境必须使用
独立测试数据库、模拟开户材料和测试账号，禁止上传真实身份证、营业执照或客户资料。
